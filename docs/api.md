# API surface (current)

Base path for domain routes: `/api/v1`.

## Health

- `GET /health`
  - Returns `{ "status": "ok" }`.

## Parcels

- `POST /api/v1/parcels/`
  - Create parcel from GeoJSON polygon/multipolygon.
  - Computes `area_ha` server-side using EPSG:3035.

- `GET /api/v1/parcels/{parcel_id}`
  - Fetch one parcel by UUID.

- `GET /api/v1/parcels/`
  - List parcels with optional filters:
    - `bbox=lon_min,lat_min,lon_max,lat_max`
    - pagination via `limit`/`offset`

- `PATCH /api/v1/parcels/{parcel_id}`
  - Partial update of parcel metadata fields.

- `DELETE /api/v1/parcels/{parcel_id}`
  - Delete parcel.

## Forecasts

- `GET /api/v1/forecasts/{parcel_id}/latest`
  - Latest available forecast for parcel.

- `GET /api/v1/forecasts/{parcel_id}/`
  - Time-ordered list with:
    - `from_time`
    - `to_time`
    - `limit`
    - `offset`

- `POST /api/v1/forecasts/trigger-ingestion`
  - Enqueues ingestion job in Redis/`arq`.
  - Query params: `source`, `bbox`, `valid_time`.

## Notes

- OpenAPI docs are auto-generated by FastAPI at `/docs`.
- Database sessions in routes are dependency-injected through `DBSession` alias (`app/api/deps.py`).
